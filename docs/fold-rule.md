# 落期口径决策：实抄按 occurred_at 折自然月入湖（架构B）

## 背景

实抄装载请求同时携带申报 `period_id` 与 `occurred_at`。若装载入口、正式表、对齐物化、
差额分桶、封印闸、批次快照、总览计数、按期列表各自折各自的账期，会出现：

- 实抄回执成功，但读数落入错误的账期闭包；
- 已封印账期被旁路（折期）撬写。

因此全局只贯彻一种落期架构。本仓库选定 **架构B**，另一候选（架构A）仅作对照记录。

## 决策（全局唯一）

1. **实抄落期 = `occurred_at` 字面日期折成的自然月（YYYY-MM）**，不做时区换算；
   请求体申报 `period_id` 落 `actuals.declared_period_id`，仅作审计。
2. **估抄无 `occurred_at`，落期 = 申报 `period_id`**（回执 `fold_rule=declared`）。
3. 落期账期不存在 → **自动开立为 open**（回执 `period_created=1`）。
4. 落期账期已封印 → **整笔拒绝**（`ON_SEALED=reject`，全局一种，**不改挂下一开放账期**）；
   拒绝回执照常落库，可核对。
5. 每笔装载（落湖/拒绝）都写 `ingest_receipts` 回执：申报账期、落期账期、折期规则、
   决策、原因、是否自动开期。
6. **闸检与写入同事务**（`BEGIN IMMEDIATE`）：正式表行与回执同生共死；
   封印与装载互斥串行，杜绝「查完闸再写」的 TOCTOU 半截写入。
7. 对齐物化、差额分桶、封印闸只扫描**落期账期**（`period_id` 列即落期）；
   批次快照记录 `fold_rule=occurred_at`、`folded_count`（折期笔数）、
   `declared_periods`（折入本期的原申报账期集合）；指纹覆盖键集合与折期笔数。
8. 总览按账期计数与按期列表同口径（`WHERE period_id=?`，`period_id` 即落期），
   并单列「其中折期」笔数。

## 正确性口径分叉：六条核对在 B 下的口径（A 对照）

| 核对 | 架构B（本仓库实现） | 架构A（未采用，对照） |
| --- | --- | --- |
| occurred_at ≠ 申报账期 | 落期 = 折期月；申报账期仅审计（核对 1.x） | 落期 = 申报账期；occurred_at 仅审计 |
| 折期后落期已封 | 整笔拒绝 409 + 拒绝回执（核对 2.x） | 不存在折期；申报账期已封即拒 |
| 已封申报账期被撬写 | 不可能：写入只落折期月；申报已封但折期落开放期 → 落开放期，已封期零新增（核对 3.3） | 申报已封即拒，无论 occurred_at 落在哪 |
| 总览与列表同期计数 | 同按落期账期计数，含折期列（核对 4.x） | 同按申报账期计数 |
| 对齐键集合随落期变化 | 键集合/指纹随折入折出变化；快照含 fold_rule/折期笔数/原申报账期（核对 5.x） | 键集合只随申报账期变化 |
| 并发折期入湖 vs 封印 | 事务串行化：落湖行数 == 200 数 == landed 回执数；封印后一律 409（核对 6.x） | 同样需要同事务闸检 |

## 联动面（缺一即口径分叉）

估抄/实抄装载入口（`ingest_service`）→ 正式表（`estimates`/`actuals.period_id` 即落期）
→ 对齐物化（`run_align` 扫落期）→ 差额分桶（`variances.period_id` 承批次落期）
→ 封印闸（`ensure_period_open_tx` 事务内检）→ 批次快照（fold_rule/folded_count/
declared_periods）→ 总览期计数（`/overview.period_counts`）→ 按期列表
（`/estimates`、`/actuals`、`/receipts` 的 period_id 过滤）。
**禁止只改列表展示账期**——落期必须落在正式表，全链路同源。

## 核对

```bash
cd backend
.venv/bin/python tests/verify_fold_rule.py
```

独立临时库 + 真实 HTTP 服务 + 真并发（24 笔折期装载与封印竞速），六项全绿退出码为 0。

## 明确不做

- 不做收银营业日封账：无营业日/班次概念，封印粒度仍是账期自然月。
- 不做双端业务流水抽取：只接估抄/实抄装载，不接源系统流水。
- 不做一次勾选多账期的封印工单：封印一次一个账期（`POST /seal` 单 `period_id`）。
